# Jekyll Blog

Site runs at: https://varje.github.io/blog/

## Requirements
- Ruby 3.1–3.2
- Bundler

## Local Setup
```bash
bundle install
bundle exec jekyll serve
```

Site runs at: http://localhost:4000

### Adding new post
1. Create a file in _posts: 
```bash
YYYY-MM-DD-title.md
```

1. Build:
```bash
bundle exec jekyll build
```
